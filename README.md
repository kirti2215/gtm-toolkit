# GTM Toolkit

For PMMs, GTM leaders, and sales teams who want AI that actually understands go-to-market. A growing collection of skills covering regional campaigns, messaging, competitive intel, and sales enablement — one skill per workflow, built to be repurposed.

Built by a GTM practitioner, for GTM practitioners. Because the best campaigns are specific, not templated.

---

## How to use

**Claude and Cowork users**
Download the `.skill` file from the `skills/` folder and install it in your Cowork or Claude Code plugins. The skill triggers automatically when you describe a campaign brief.

**Everyone else (ChatGPT, Gemini, Copilot, in-house bots)**
Copy the prompt from the `prompts/` folder and paste it at the start of any AI conversation. Works with any LLM.

---

## Skills

### GTM Regional Campaign Builder
Drop in your product, region, industry, and audience and get a complete campaign brief in minutes. The skill researches current regional context automatically, then builds a brief with messaging, business case, target accounts, and success metrics — adapted for executive buyers, technical buyers, or internal sales teams.

Inputs it takes: product, region, vertical, campaign objective, audience type, pipeline numbers, target accounts, reference customer, and any existing internal docs you want reframed.
