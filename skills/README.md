# GTM Skills

This directory contains reusable AI Skills for common go-to-market workflows.

Each Skill packages a repeatable way of thinking into a structured workflow with clear inputs, decision logic, guardrails, and outputs. Rather than generating generic content, these Skills diagnose the business context first and adapt their recommendations accordingly.

## Repository Structure

```
skills/
├── battle_card/
├── product_launch/
├── sales_enablement/
└── ROADMAP.md
```

Each Skill includes:

- `README.md` — Overview, methodology, and usage
- `input-template.md` — Information required before running the Skill
- `example-input.md` — Fictional example input
- `example-output.md` — Example output generated by the Skill

---

## Current Skills

### Competitive Battle Card

Diagnoses the competitive motion before generating content.

Produces account-specific competitive positioning, objection handling, buyer insights, and recommended deal strategy.

---

### Product Launch Planner

Identifies the "why now" before building a launch package.

Produces a launch strategy brief, messaging framework, buyer personas, seller enablement, technical enablement, objection handling, and launch-readiness checklist.

---

### Sales Enablement

Builds account-specific sales materials for enterprise opportunities.

Produces buyer-specific value propositions, discovery questions, pitch points, objection handling, business cases with assumptions clearly labeled, and recommended next steps.

---

## Design Principles

All Skills in this repository follow the same principles:

- Diagnose before generating content.
- Adapt recommendations to the customer, market, or opportunity.
- Separate verified evidence from assumptions.
- Produce outputs that help move a business decision forward.
